# Quant Roadmap

Личный трекер прогресса на пути к позиции quant developer: C++, математика, теория вероятностей, стохастические процессы.

Сайт: https://kayyooo23.github.io/quant-roadmap/

Один файл `index.html`, без бэкенда. Прогресс хранится в `localStorage` браузера, поэтому на каждом устройстве он свой.

## Как менять контент

Все темы и их стартовые статусы (`pending` / `learning` / `done` / `skip`) заданы в объекте `DATA` в начале `<script>` внутри `index.html`. Чтобы добавить тему, добавь строку в нужную группу `topics` с новым уникальным `id`. Отметки, сделанные на сайте, хранятся по `id`, поэтому при изменении `id` у существующей темы её отметка сбросится.
